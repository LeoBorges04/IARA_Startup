🧠 IARA — Project Model Canvas

Plataforma de Inteligência Artificial para Raciocínio Algorítmico (Tutora Virtual RAG)

José Finocchio Jr. Template Agosto / 2026 Versão MVP 1.0
💬 Justificativas Passado
  • Altas taxas de retenção/reprovação em disciplinas de Algoritmos e Programação.
  • Sobrecarga de tutores e monitores para atendimento individualizado contínuo.
  • Ferramentas genéricas (ChatGPT) entregam o código pronto sem ensinar a lógica.
  • Falta de personalização alinhada com as ementas da instituição.
🎯 Obj SMART
  • Específico: Desenvolver tutora IARA com RAG para ensino socrático.
  • Mensurável: Reduzir retenção em 25% e atingir >90% de precisão RAG.
  • Atingível: Arquitetura FastAPI + MongoDB + OpenAI + HTML/JS.
  • Relevante: Combate evasão em cursos de Engenharia e Computação.
  • Temporal: Lançamento da V1.0 em 6 meses.
📈 Benefícios Futuro
  • Desenvolvimento de raciocínio algorítmico guiado (método socrático).
  • Atendimento pedagógico adaptativo disponível 24/7.
  • Redução de evasão universitária em cursos STEM.
  • Autonomia de docentes no gerenciamento de conteúdos e ontologias.
📦 Produto
  • Plataforma Web IARA (Chat interativo + Markdown + Syntax Highlighting).
  • Backend Python (FastAPI) com suporte a JWT e MongoDB Atlas.
  • Engine RAG com busca vetorial e catálogo de exercícios por fases (1-4).
  • Painel Administrativo para upload e gestão de bases RAG.
📝 Requisitos
  • RF01: Autenticação de usuários (Alunos/Admins).
  • RF02: Interface de Chat com histórico persistente.
  • RF03: Busca semântica vetorial RAG contextualizada.
  • RF04: Moderação pedagógica (dicas sem dar código pronto).
  • RF05: Painel Admin para ingestão de novas ontologias.
  • RNF01: Ergonomia cognitiva (validada via Wireframe).
  • RNF02: Resposta do RAG + IA em até 3 segundos.
  • RNF03: Segurança de dados e sanitização NoSQL.
🌐 Stakeholders Externos
  • Estudantes Universitários de Computação e Engenharia.
  • Professores e Coordenadores Didáticos.
  • Provedores de APIs (OpenAI GPT & Embeddings).
  • Banco em Nuvem (MongoDB Atlas Vector Search).
👥 Equipe
  • Gerente de Projeto / Scrum Master.
  • Desenvolvedor Backend (Python / FastAPI / MongoDB).
  • Desenvolvedor Frontend & Designer UX/UI.
  • Engenheiro de IA & Prompt Engineer.
  • Curador Pedagógico (Conteudista de Algoritmos).
🚫 Restrições
  • Prazo máximo de entrega do MVP em 6 meses.
  • Teto de custos mensais para consumo da API OpenAI.
  • Uso estrito da stack definida (FastAPI/MongoDB/Vanilla JS).
  • Conformidade total com a LGPD e privacidade dos dados.
💭 Premissas
  • Alunos possuem acesso regular a computadores/internet.
  • APIs da OpenAI e MongoDB Atlas com alta disponibilidade.
  • Docentes fornecerão listas e ementas atualizadas.
  • Arquitetura em FastAPI atenderá o volume sem gargalos.
📦 Grupo de Entregas
  • E01: Elicitação, Arquitetura e Wireframes.
  • E02: API FastAPI, Autenticação e Banco MongoDB.
  • E03: Ingestão RAG (Ontologias Fases 1-4) & Fine-tuning.
  • E04: Frontend Web (index, admin, login) e JS.
  • E05: Testes de Usabilidade com Piloto e Deploy.
⚠️ Riscos
  • Estouro de orçamento de tokens da API OpenAI.
  • "Alucinação" da IA em conceitos avançados de código.
  • Baixa adoção por parte dos estudantes.
  • Latência de resposta da chamada RAG/LLM.
📅 Linha do Tempo
  • M1: Requisitos, Canvas & Wireframes.
  • M2: Backend FastAPI, MongoDB & Auth.
  • M3: Ingestão RAG & Estruturação de Prompts.
  • M4: Frontend Web & Painel Admin.
  • M5: Testes Piloto & Otimização RAG.
  • M6: Deploy MVP 1.0 & Lançamento.
