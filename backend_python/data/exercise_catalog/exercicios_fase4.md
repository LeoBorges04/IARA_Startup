## Caixa Eletrônico - Saque em Notas
Categoria: Exercícios Integradores
Ontologia: Problemas de Classificação
Dificuldade: Avançado
Descrição: Simular o saque em um caixa eletrônico calculando a menor quantidade de cédulas (R$ 100, 50, 20, 10, 5, 2) necessárias para compor o valor.
Conceitos envolvidos:
- Operador Módulo %
- Divisão inteira /
- Condicionais encadeadas if/else
- Laço de repetição do-while
