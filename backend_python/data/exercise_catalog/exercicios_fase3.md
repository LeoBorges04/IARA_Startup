## Busca linear em vetor
Categoria: Busca
Ontologia: Problemas de Busca
Dificuldade: Fácil
Descrição: Percorrer um vetor elemento por elemento até encontrar um valor procurado ou chegar ao final.
Conceitos envolvidos:
- Vetores
- Laço de repetição for
- Estrutura condicional if
- Flag de busca ou índice encontrado
